# Credit Card Spend Prediction

Predict customer credit card spend using data from an Amex hackathon.

## Approach

- Extensive exploratory analysis and feature engineering
- Linear Regression and Random Forest baselines
- XGBoost and LightGBM regressors

Hackathon train and test files, included.
